# ADS-lab2

## Лабораторная работа №2. Вариант №4 - Двусвязный циклический список

## Автор

Эльменкин Виктор Хавьерович 6213

## Описание

Шаблонная структура для представления элементов списка: `Node` 

Шаблонный класс `LinkedList<T>` — двусвязный список

с перегрузкой методов и поддержкой C++23 модулей.


## Возможности

- Конструктор по умолчанию.
- Конструктор копирования.
- Конструктор, заполняющий список случайными значениями согласно заданию.

## Сборка

cmake -G Ninja -B build
cmake --build build


## Запуск

.\build\ADS\lab2.exe
