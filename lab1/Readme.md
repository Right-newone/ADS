Общие требования
1. В данной работе вы не должны использовать контейнеры STL кроме std::string и std::complex .
2. Класс должен быть копируемым и непосредственно управлять выделяемым ресурсом.
3. Класс должен предоставлять операторы сравнения на равенство и неравенство. Сравнение вещественных чисел должно происходить с определённой точностью, которая задаётся, например, константным статическим полем класса.
4. Класс должен перегружать оператор вывода без использования си-шных потоков (см. пункт 6)
5. В случае некорректности аргументов должны кидаться исключения через stdexcept. К некорректным ситуациям относятся обращение по несуществующему индексу, вызов операции сложения для двух векторов разного размера и тому подобное.
6. Весь ввод-вывод должен осуществляться исключительно через std::cin и std::cout, без использования (явного или неявного) си-шных потоков stdin и stdout.
7. Разрешено пользоваться генераторами случайных чисел из <random>.
8. Продумывать логику так, чтобы наибольшее число операторов/методов использовалось в последующих методах.
9. Решение задач должно быть расположено вне класса.
10. В main() должна быть продемонстрирована работоспособность всех операторов и методов на случайно сгенерированном объекте класса.

11. Проверка типов должна выполняться на этапе компиляции, а не во время выполнения программы. Для различения операций над данными разных типов необходимо использовать шаблоны и перегрузку операторов. Запрещена проверка и выбор поведения по типу данных во время выполнения (typeid, dynamic_cast, ветвление по тегу/enum типа и т. п.).
