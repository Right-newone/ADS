# ADS-lab1

## Лабораторная работа №1:Полутонные изображения

## Автор

Эльменкин Виктор

## Описание


Шаблонный класс `image<T>` — изображение произвольного размера

с перегрузкой операторов и поддержкой C++23 модулей.


## Возможности


- Конструкторы: с заполнением и со случайными значениями

- Операторы: `+`, `-`, `*`, `=`, `==`, `!`, `()`, `<<` 


## Сборка

cmake -G Ninja -B build
cmake --build build


## Запуск

.\build\ASD\lab1.exe
